# `pyproject.toml` declares floors (`fastapi>=0.115`), which is the right thing for a package and
# the wrong thing for a deployable artefact: two builds of the same commit, a week apart, would
# install different versions, and a green CI run would then say nothing about what production
# actually runs. This file closes that gap — `Dockerfile` installs with
# `pip install --constraint constraints.txt .`, so the resolver may still build the graph from
# `pyproject.toml` but may not choose a version other than the one pinned here.
#
# A dependency added to `pyproject.toml` without a matching pin here fails the image build rather
# than floating silently. That is the intended behaviour, and it is the reminder to regenerate.
#

# image's own base, so the pins describe the platform Render runs:

#         set -e
#         pip install --quiet --upgrade pip setuptools wheel
#         cp -r /src /build && cd /build
#         pip install --quiet .
#         pip freeze --exclude-editable
#     ' | grep -v "^weathra==" | sort -f
